# AccrediAI
AI-based analysis and generation of performance indicators from SRR PDF documents submitted by academic institutions to support approval and evaluation processes conducted by AICTE and UGC.

The platform automatically extracts and analyzes important institutional data from SSR PDF documents and generates intelligent insights, summaries, and approval-related evaluations. 

Features
1. Upload SSR (Self-Study Report) PDF files
2. AI-powered analysis using Gemini AI
3. Automatic extraction of:
Faculty information

PhD holder statistics

Full-time faculty count

Research and publication details

Infrastructure data
